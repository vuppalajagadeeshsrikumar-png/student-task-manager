# 📚 Student Task Manager

A simple and user-friendly task management web application designed
to help students organize their assignments, deadlines, subjects,
and priorities.

## ✨ Features

- ➕ Add tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📚 Organize tasks by subject
- 🔴 Set task priorities
- 📅 Add deadlines
- ⏰ Deadline warnings
- 🔎 Search tasks
- 🔽 Filter tasks
- 📊 Task statistics
- 📈 Progress tracking
- 🌙 Dark mode
- 💾 Data saved using Local Storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git & GitHub

## 🎯 Purpose

This project was created as a student portfolio project to practice
frontend web development, JavaScript, DOM manipulation, event handling,
and browser Local Storage.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Start adding your tasks.
